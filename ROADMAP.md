# Roadmap

| Milestone | Essential scope | Exit gate | Optional/deferred |
| --- | --- | --- | --- |
| Foundation (current) | Documentation, manifests, health, landing page, checks, CI definition | Local checks recorded; remote CI pending | No classifier or persistence |
| MVP (Phases 1–4) | Validated uploads, one crop/class set, reproducible model, confidence/uncertainty, reviewed descriptions, responsive UI | SPEC.md MVP criteria and working local end-to-end flow | Accounts, history, monitoring |
| Version 1.0 (Phase 5) | Package and deploy MVP, production configuration, smoke checks, operating guide | Hosted flow verified with resource/security limits | Additional hosting services |
| Version 1.1 | Prioritize feedback, optionally accounts/history and additional crops with evaluation | Ownership/retention tests and per-crop evidence | Model monitoring dashboard |
| Future versions | Mobile API client and camera capture after stable API | Separate scoped requirements and acceptance | Severity estimation, real-time monitoring, field experiments |

Complete an inexpensive functioning MVP before adding infrastructure or broader crop support.
Dates are intentionally unset; task dependencies and evidence determine progress. Future
improvements are candidates, not release promises. See TASKS.md for actionable work.
